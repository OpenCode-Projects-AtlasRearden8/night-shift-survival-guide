# Night Shift Survival Guide

A warm, plain-English survival manual for night-shift workers — written
nurse-flavored, by [Dylan Asdale, RN](https://dylanasdale.github.io) and
published by **Asdale Dynamics, LLC**.

It covers the real mechanics of living around night shifts:

- **Sleep-window planning** — anchor sleep, split schedules, pre-shift naps
- **Daytime-sleep environment setup** — dark, quiet, cool, boring
- **Light and caffeine timing** — sunglasses on the drive home, caffeine half-lives
- **Meals and snack tactics** — the evening-is-your-morning food plan
- **Driving-home safety** — sleepiness signs, countermeasures, a do-not-drive ladder
- **Family-boundary scripts** — copy-paste scripts for partners, kids, parents, neighbors
- **A low-energy recovery day plan** — three gentle blocks, zero willpower required
- **Shift-cycle planner worksheet** — one page that turns the book into a routine
- **Glossary** — every term in plain English

Built and maintained by **Asdale Dynamics, LLC** as part of its line of
beginner-friendly, warm, practical guides.

> **Education only.** This manual is not medical advice. For anything about your
> health — sleep disorders, medications, chronic exhaustion, anything clinical —
> talk to your own clinician or employee health nurse.

## Quick start

The build has zero dependencies (Python 3.8+ standard library only) and the
site works fully offline — no external fonts, scripts, trackers, or network
calls of any kind.

```bash
python3 build.py        # generates the static site into ./site
```

Then open `site/index.html` in any browser. That's it.

To rebuild the site from scratch:

```bash
make clean && make build    # or: python3 build.py --clean
```

## Tests

The test suite builds the real site into a temporary directory and checks
output inventory, page chrome, link integrity, anchor targets, worksheet
interactivity, glossary coverage, and that the build is byte-for-byte
deterministic.

```bash
python3 -m unittest discover -s tests -v    # or: make test
```

## Project structure

```
night-shift-survival-guide/
├── build.py                # markdown → static HTML, stdlib only
├── docs/                   # the manual (10 chapters + worksheet + glossary)
│   ├── 00-introduction.md
│   ├── 01-sleep-window-planning.md
│   ├── 02-daytime-sleep-environment.md
│   ├── 03-light-and-caffeine-timing.md
│   ├── 04-meals-and-snacks.md
│   ├── 05-driving-home-safety.md
│   ├── 06-family-boundary-scripts.md
│   ├── 07-low-energy-recovery-day.md
│   ├── 08-shift-cycle-planner.md
│   └── 09-glossary.md
├── templates/              # page.html + styles.css (warm theme, print-tuned)
├── site/                   # generated output (safe to delete and rebuild)
├── tests/                  # unittest suite for the build
└── Makefile
```

The markdown source in `docs/` is the single source of truth; `site/` is
regenerated by the build script. The mini-markdown renderer supports headings
(with auto anchors), bold, italics, inline code, links (`.md` targets are
rewritten to `.html` automatically), nested lists, task-list checkboxes,
tables, blockquotes, and horizontal rules.

## Design principles

- **Local-first** — no CDNs, no analytics, no cookies, no accounts. Nothing
  leaves your machine.
- **Warm, never condescending** — small paragraphs, real shift-life examples,
  honest about what works and what doesn't.
- **Education-only** — clearly labeled as such, on every page, in the footer.
- **Printable** — every page, including the worksheet, is print-tuned.
